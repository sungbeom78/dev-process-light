# light-portal — 기록 보기 페이지

`dev-notes/` 의 기록과 git 저장 목록으로 **HTML 파일 하나**를 만든다. 서버도 로그인도 없고, 내 컴퓨터에서 브라우저로 연다.
인터넷에 올리지 않는다.

## 어디에 만들지 (처음 한 번만 묻는다)
`dev-notes/NOW.md` 의 `## 설정` 에서 `기록 보기 페이지:` 를 본다.

- 정해져 있으면 그 경로에 만든다.
- `(아직 정하지 않음)` 이면 만들기 전에 이렇게 묻는다 (작업 합의와 별개인 준비 질문):
  ```
  지금까지의 기록을 한눈에 보는 페이지를 만들 수 있어요. 내 컴퓨터에서 브라우저로 여는 파일이고, 인터넷에 올라가지 않아요.
   1. 이 폴더 안 dev-notes/portal.html 에 만들기 (추천 -- 잘 모르겠으면 이것)
   2. 다른 폴더에 만들기 (경로를 알려 주세요)
   3. 만들지 않기
  ```
  답을 `## 설정` 에 적고(`- 기록 보기 페이지: dev-notes/portal.html` 또는 `만들지 않음`),
  `DECISIONS.md` 에 `[사용자]` 결정으로 답 그대로 한 줄 남긴다.
- **사이트로 공개되는 폴더(예: GitHub Pages 로 올리는 폴더) 안에는 만들지 않는다.** 기록이 인터넷에 보이게 된다.

## 만들기
```
python .claude/skills/light-portal/portal_tool.py build --out dev-notes/portal.html
```
(Codex 는 `.agents/skills/...`. Windows 에서 `python` 이 없으면 `py`.)
- 프로젝트 안에 만들면 도구가 `.gitignore` 에 넣는다 -- 기록에서 언제든 다시 만들 수 있어 저장하지 않는다.
- 파이썬이 없으면 만들지 않고, "기록은 `dev-notes/` 의 파일을 열어 보면 된다"고 알려 준다.
- 끝나면 열 주소(`file://...`)를 알려 준다.

## 페이지에 있는 것
| 메뉴 | 내용 |
|---|---|
| 지금 | 기능 수·문제·저장 수, 저장 안 된 변경, `NOW.md` |
| 기능 | `FEATURES.md` (기능 지도) |
| 결정 | `DECISIONS.md` -- 사용자가 정한 것 / AI 가 정한 것을 나눠서 |
| 작업 기록 | `LOG.md` (+ `dev-notes/log/` 의 지난달) -- 단계별로 골라 보기 |
| 저장 | git 저장 목록 (되돌아올 수 있는 지점) |
| 이름표 | `NAMES.md` |
| 사용설명서 | `manual/index.html` 이 있으면 바로 가기 |

## 언제 다시 만드나
- `light-save` 가 저장할 때마다 (설정이 `만들지 않음` 이 아니면)
- 사용자가 "기록 보여 줘" 라고 할 때
