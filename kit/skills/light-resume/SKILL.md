# light-resume — 이어하기

## 언제
- 새 대화·새 세션을 시작할 때 (사용자가 아무 말 없이 기능을 요청해도 먼저 한다)
- 사용자가 "어디까지 했지?", "이어서 하자"라고 할 때

## 순서
1. 읽는다: `dev-notes/NOW.md`, `dev-notes/FEATURES.md`, `dev-notes/NAMES.md`
2. 확인한다:
   - `git status` -- 저장하지 않은 변경이 있는가
   - `git log --oneline -5` -- 최근 저장 5개
3. 사용자에게 5줄 이내로 말한다:
   ```
   지금 상황: <이 프로젝트 한 줄>
   마지막 저장: <날짜·내용>
   진행 중이던 작업: <NOW.md 의 지금 작업, 없으면 "없음">
   저장 안 된 변경: <있음(파일 몇 개) / 없음>
   다음 할 일: <NOW.md 의 다음에 할 일 첫 줄>
   ```
4. 저장 안 된 변경이 있으면: 무엇인지 보여주고 "이어서 마저 할지 / 되돌릴지(light-undo)"를 묻는다. 마음대로 지우지 않는다.

## 처음 쓰는 프로젝트일 때
`dev-notes/` 가 없거나 `NOW.md` 의 "이 프로젝트는" 이 비어 있으면:
1. `git status` 가 실패하면(아직 git 이 아니면) 사용자에게 알리고 `git init` 한다.
   `.gitignore` 가 없으면 만든다 (비밀 설정 파일·`node_modules/`·`.env` 등).
2. 사용자에게 묻는다: "무엇을 만드는 사이트인가요? 들어갈 기능을 생각나는 대로 말해 주세요."
3. 답을 `NOW.md` 의 "이 프로젝트는" 과 "다음에 할 일" 에 적고, 이미 있는 파일이 있으면 살펴서
   `FEATURES.md` 에 기능별로 정리한다 (모르는 것은 "확인 필요"로 적는다).
4. 첫 저장(`light-save`)을 한다: "준비: 작업 기록 시작".

## 하지 않는 것
- 기록을 읽지 않고 바로 코드를 고치기
- NOW.md 에 없는 내용을 지어내기 (모르면 "기록 없음"이라고 말한다)
