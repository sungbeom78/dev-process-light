# 나의 홈 사용설명서

나 혼자 쓰는 홈페이지입니다. 메모, 할 일, 가계부를 한곳에서 씁니다.
인터넷 연결이나 회원 가입 없이, 이 컴퓨터의 브라우저에만 저장됩니다.

## 시작하기

1. `index.html` 파일을 두 번 눌러 브라우저로 엽니다.
2. 위쪽에 [메모] [할 일] [가계부] 버튼이 보입니다. 누르면 그 화면으로 바뀝니다.

## 기능 목록

- [메모](memo.md) -- 짧은 메모를 적고 지웁니다
- [할 일](todo.md) -- 할 일을 적고, 끝나면 체크합니다
- [가계부](budget.md) -- 쓴 돈을 적고 이번 달 합계를 봅니다
