# 기능 지도

> 이 사이트에 어떤 기능이 있고, 각 기능이 어떤 파일을 쓰는지 적습니다.
> AI는 고치기 전에 이 표를 보고 "다른 기능을 건드리는지" 확인하고, 고친 뒤에는 모든 기능을 한 번씩 점검합니다.

| 기능 | 상태 | 쓰는 파일 | 확인 방법 (한 줄) | 설명서 |
|---|---|---|---|---|
| 메모 | ✅ 동작 | memo.js | 메모를 쓰고 새로고침해도 남아 있다 | manual/memo.html |
| 할 일 | ✅ 동작 | todo.js | 할 일을 적고 체크 → 맨 아래로 가고, 새로고침해도 체크·줄긋기가 남아 있다 | manual/todo.html |
| 가계부 | ✅ 동작 | budget.js | 항목·금액 2건 입력 → 새로고침해도 이번 달 합계가 맞다 | manual/budget.html |

상태: ✅ 동작 · 🚧 만드는 중 · ⚠️ 문제 있음 · 💤 쉬는 중

## 함께 쓰는 파일
여러 기능이 같이 쓰는 파일입니다. 이 파일을 고치면 **모든 기능**을 점검합니다.
- index.html (화면 틀·탭 메뉴), style.css (모양), tabs.js (탭 전환), store.js (저장 -- 저장 이름을 바꾸면 예전 데이터가 안 보임)
